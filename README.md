# MT-SAM
The Pytorch implementation of MT-SAM: A Mamba-Transformer Enhanced SAM with Prior-guided Prompting for Multi-modal Prostate Cancer Delineation

This project is built upon and fully compatible with [nnUNetv2](https://github.com/MIC-DKFZ/nnUNet). The entire pipeline—data organization, preprocessing, training, validation, and inference—follows nnUNetv2 standards.
